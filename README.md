# Speedi Meal Planer

Mobile Web-App als Ersatz für den „Speedi Meal Builder“ für den Ninja Speedi (ON400EU), Programm Speedi Meals.

- `index.html` läuft allein, offline, ohne Server (Daten im localStorage des Browsers).
- `sw.js`, `manifest.webmanifest`, `icon.svg` sind optional: nur für Hosting (z. B. GitHub Pages), damit die App als Homescreen-App offline startet.
